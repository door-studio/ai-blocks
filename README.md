# AI Blocks

用积木搭 AI —— 一个看得见、摸得着的机器学习教学工具。

不用装任何第三方库，纯 Python + Tkinter，双击就能跑。拖几块积木连起来，
点一下运行，就能看着神经网络从一团乱麻慢慢学会分类、看着马尔可夫链一个字
一个字地续写、看着遗传算法把一群候选解进化成最优答案。

## 六个板块

| 板块 | 干什么 |
| --- | --- |
| 神经网络 NN | 亲手搭网络结构，实时看损失下降、决策边界弯折，最后用它做预测 |
| 马尔可夫链 MK | 统计每个字后面最常跟哪个字，按概率往下接，GPT 的极简前身 |
| 预设回答 QA | 人工写死规则、关键词匹配查表，用来当反面教材 |
| 经典算法 CL | KNN 邻居投票、K-Means 簇心挪位、遗传算法自然选择 |
| 声音识别 AU | 把 wav 压成特征数字喂给网络，按文件夹分类别，学会听声辨类 |
| 图片识别 IM | 把图片缩成 8x8 灰度向量喂给网络，支持画板手写识别 |

## 运行

需要 Python 3.8+（标准库即可，无需 pip install）。

```bash
python main.py
```

Windows 上也可以直接双击 `main.py`。

## 模型导出

任何训好的模型都能导出成一个通用 JSON 文件，任何语言都能读：

```
board/
  你的模型.json        训练好的权重
  你的模型_infer.py    零依赖推理脚本，只用 json / math / sys / random
```

JSON 结构：

```json
{
  "format": "aiblocks-model",
  "version": 1,
  "saved_at": "2026-01-01T12:00:00",
  "board": "nn",
  "model": { "type": "mlp", "weights": [[...]], "biases": [[...]], "...": "..." }
}
```

支持的类型：`mlp`、`markov`、`qabot`、`knn`、`kmeans`、`ga`、`recog`。

## 数据格式

刻意做得宽容，怎么写都能读：

* 分隔符：逗号 / 制表符 / 分号 / 空格 都行
* 表头：可有可无，自动识别
* 标签：最后一列不是数字就当标签；全是数字就当无标签
* 问答库：`关键词,回答`、`关键词 = 回答`、`关键词：回答` 都行；
  一个问题的多个说法用 `$%` 隔开，如 `你好$%hi$%hello`

识别板块用文件夹组织样本，子文件夹名就是类别名：

```
你的样本/
  类别A/  1.wav  2.wav
  类别B/  3.wav  4.wav
```

音频支持 wav；图片支持 png / gif / bmp / ppm（手写解码，不依赖 Pillow）。

## 目录结构

```
main.py          程序入口
app.py           主界面、积木执行引擎、可视化调度
blocks_def.py    所有积木的定义（标签、输入、悬停说明）
block_view.py    单块积木的绘制与拖拽
ai_core.py       模型实现 + 特征提取 + 模型导出导入
visuals.py       右侧可视化面板（折线、散点、热力图、网络图、概率条）
i18n.py          中英双语文案
themes.py        配色常量
```
